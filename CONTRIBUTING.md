# Contributing to ONEFORALL

Thanks for your interest in contributing! 🎉

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR-USERNAME/oneforall.git`
3. Install dependencies: `npm install`
4. Create a feature branch: `git checkout -b feature/your-feature`

## Development

```bash
# Run the CLI locally
node bin/ofa.js --help

# Run tests
npm test

# Link for local development
npm link
```

## Pull Request Process

1. Ensure your changes include appropriate tests
2. Update documentation if needed
3. Keep commits focused and well-described
4. Submit a PR with a clear description of the changes

## Code Style

- Use ES modules (`import`/`export`)
- Follow existing code patterns
- Add JSDoc comments for public functions
- Keep functions small and focused

## Reporting Issues

- Use GitHub Issues
- Include steps to reproduce
- Include your Node.js version and OS
